title: Como a busca funciona
doc: search.overview
---
Cada palavra que você digita precisa corresponder a algo em um registro, então acrescentar uma palavra estreita os resultados em vez de ampliá-los. Uma palavra corresponde a partir do começo, então "spi" encontra "Spider-Man".

Maiúsculas e pontuação são ignoradas, então "asm-300", "asm 300" e "ASM_300" se comportam da mesma forma. Letras isoladas nunca são indexadas sozinhas, então uma busca feita só delas devolve nada em vez de tudo.
